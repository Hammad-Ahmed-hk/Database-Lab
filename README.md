# Database Systems: Lab Tasks

Lab work for a university Database Systems course: lab reports (`.docx`) with the SQL scripts behind them, plus a closing open-ended lab.

## Labs

| Folder | What's included | SQL topics |
|---|---|---|
| [`Lab_1`](Lab_1) | Report and a Microsoft Access database (`.accdb`) | Introduction to databases |
| [`Lab_02`](Lab_02), [`Lab_03`](Lab_03) | Report | n/a |
| [`Lab_04`](Lab_04) | Report and SQL script | Creating a database and tables, `ALTER TABLE` |
| [`Lab_05`](Lab_05) | Report and SQL script | `ALTER TABLE`, `SELECT` |
| [`Lab_06`](Lab_06) | Report and SQL script | `INSERT`, `UPDATE`, `DELETE`, `SELECT` |
| [`Lab_07`](Lab_07) | Report and SQL script | Joins and `GROUP BY` |
| [`Lab_08`](Lab_08) | Report and SQL script | Aggregates (`COUNT`) and `GROUP BY` |
| [`Lab_09`](Lab_09) | Report and SQL script | Creating tables, inserting data, `SELECT` |
| [`Lab_10`](Lab_10) | Report | n/a |
| [`Lab_11`](Lab_11) | Report and SQL script | Views, joins, `GROUP BY` |
| [`Lab_12`](Lab_12) | Report and SQL script | `CASE` expressions and queries |
| [`Lab_13`](Lab_13) | Report | n/a |
| [`OEL`](OEL) | Report and SQL script | **Open-ended lab:** a 12-table schema with data, joins, a view and grouped queries |

## How to use

- Open the `.docx` report in each folder for the task description and screenshots.
- Run the `.sql` scripts in a SQL client (for example SQL Server Management Studio). Some scripts create the database first, so run them in a test environment.
- `Lab_1/hammad_ahmed.accdb` opens in Microsoft Access.
